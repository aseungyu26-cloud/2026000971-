# 📌 안티그래비티 기반 다중 게시판 시스템 (Vibe Coding 실습)

안티그래비티(Anti-gravity) AI 에이전트와 Node.js, Git CMD를 활용하여 단계별로 확장 가능하도록 설계된 **다중 운영 공간 및 게시판 시스템**입니다.

---

## 🛠️ 개발 환경 및 사용 기술
* **AI IDE:** Google Antigravity (바이브 코딩 실습)
* **Backend:** Node.js, Express
* **Database:** Local Memory Array (임시 저장 방식)
* **Frontend:** HTML5, Tailwind CSS
* **Version Control:** Git CMD, GitHub

---

## 🚀 실행 및 사용 방법

### 1) 사전 준비 사항
컴퓨터에 [Node.js](https://nodejs.org)가 설치되어 있어야 합니다.

### 2) 서버 실행하기
Git CMD 또는 터미널을 열고 프로젝트 폴더로 이동한 후 아래 명령어를 입력합니다.
```bash
node server.js
```

### 3) 브라우저 접속하기
서버가 작동하면 인터넷 브라우저를 열고 아래 주소로 접속합니다.
👉 **http://localhost:3000**

---

## 📋 핵심 구현 기능 (단계별 확장 설계)

### 1단계: 단순 게시판 (완료)
* 일반 사용자의 회원가입 및 로그인 기능
* 게시글 목록 조회, 상세 보기, 글쓰기 기능
* 내가 작성한 글만 수정 및 삭제 가능 (작성자 권한 검증)
* 관리자 전용 권한 분리 및 공지사항 등록 기능

### 2단계: 다중 게시판 시스템 (확장 예정)
* 관리자가 '공지사항', '자유게시판', '질문게시판' 등 여러 게시판을 생성하고 분리하는 기능

### 3단계: 복합 다중 게시판 시스템 (확장 예정)
* 최고 관리자가 지정한 '운영 공간(Space)'별로 독립된 다중 게시판 및 사용자 접근 차단 기능

---

## 🧪 점검 및 테스트 기준
* **작성자 검증:** 사용자 B가 사용자 A가 작성한 글을 임의로 수정하거나 삭제할 수 없는지 API 권한을 체크합니다.
* **접근 제어:** 일반 사용자가 URL 주소창에 관리자 경로를 직접 입력하더라도 서버단에서 요청이 거부되는지 검증합니다.
